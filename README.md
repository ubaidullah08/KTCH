# KTCH — Indian Restaurant Order & Kitchen Workflow System

KTCH is a modern, responsive restaurant ordering, table management, and Kitchen Display System (KDS) web application for an authentic North & South Indian restaurant.

## Features
- **8-Table Floor Plan & POS:** Live table status tracking (Available, In Prep, Ready, Served) and table-bound ordering.
- **Digital Menu (78 Items):** Filterable across 7 Indian cuisine categories (*Starters & Chaat*, *Curries & Mains*, *Biryani & Rice*, *Breads*, *South Indian*, *Beverages*, *Sweet Treats*), with live search, sorting, and item customization (spice level, extras, kitchen notes).
- **Shopping Cart & Billing:** Slide-in cart drawer with ₹ INR formatting, 5% GST calculation, and printable official receipts.
- **Kitchen Display System (KDS):** Real-time order queue, preparation status transitions, bill settlement, and order history log.
- **Table Reservations:** Interactive reservation modal for dine-in bookings.
